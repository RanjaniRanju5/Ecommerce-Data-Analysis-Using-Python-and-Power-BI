## E-commerce Data Analysis Using Python and Power BI

# Project Overview

This project focuses on analyzing e-commerce business data to identify business trends, understand customer behaviour, evaluate product performance, and generate actionable business insights.

# Dataset Description

The project contains five datasets:

Customers – Customer demographic and registration details.

Products – Product information, categories, prices and costs.

Orders – Order dates, payment methods, order status and amounts.

Order Items – Product-level order details, quantities and prices.

Returns – Product returns, reasons, refund amounts and statuses.

Data Cleaning

Performed data cleaning using Python and Pandas.

Identified and handled missing values.

Removed duplicate records.

Corrected data types.

Handled negative and invalid values.

Identified and treated outliers using the IQR method.

Standardized categorical values.

Validated cleaned datasets.
